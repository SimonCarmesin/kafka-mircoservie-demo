# Goal
Create a clear review-ready summary for a code change.

# Instructions
When this skill is used:

1. Summarize the change in plain language.
2. List affected services.
3. List affected Kafka topics and event flows.
4. Explain how to test the change locally and with Docker.
5. Mention any follow-up work or limitations.

# Output format
## Summary
## Changed services
## Kafka impact
## Test steps
## Notes for reviewer
