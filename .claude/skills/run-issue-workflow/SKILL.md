# Goal
Handle a repository issue end to end using the default workflow.

# Instructions
1. Read the issue carefully.
2. Identify affected services, Kafka topics, event flows, configs, and Docker Compose impact.
3. Produce a short implementation plan.
4. Implement only after the plan is clear or approved.
5. Verify with build/test/run steps when possible.
6. Prepare a PR-ready summary.

# Output format
## Issue summary
## Scope
## Plan
## Implementation
## Verification
## PR summary
